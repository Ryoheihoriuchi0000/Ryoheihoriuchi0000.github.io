# Privacy Policy

Darwin (the "Service") handles user personal information as described below.

## 1. Information We Collect

- Email address
- Display name
- Device information
- Usage data (access logs, etc.)
- Apple ID information when using Sign in with Apple
- Game data such as characters and habitats

## 2. Purpose of Use

- Providing and operating the Service
- Improving and developing the Service
- Preventing fraudulent use
- Responding to inquiries

## 3. Third-Party Services

We may use the following services:

- Firebase (Google LLC)
- Google Analytics

Data may be transmitted to these providers. Please review each service's privacy policy.

## 4. Retention Period

We retain data only for the period necessary to provide the Service. Related data is deleted when an account is deleted.

## 5. Data Deletion

Users can delete their account from the Settings screen. After deletion, all personal information and game data are erased.

## 6. Security

We implement appropriate security measures to prevent leakage, loss, or alteration of personal information.

## 7. Children's Privacy

This Service is not intended for children under the age of 13. We do not knowingly collect personal information from children under 13.

## 8. Push Notifications

This app uses Firebase Cloud Messaging (FCM) to deliver push notifications. We collect and store the device token required to deliver notifications. Device tokens are not used for any purpose other than notification delivery. Push notifications can be turned off at any time from the app's settings.

## 9. Chat Feature

This app provides a chat feature for in-team communication. Sent messages are stored on the server (Firebase Firestore). Messages include the sender's display name and character information.

## 10. Block and Report Features

Users may report inappropriate messages and block other users. Report content (reason for reporting and the relevant message) is stored on the server, and the operators review it for the purpose of improving the Service and ensuring safety. A blocked user is removed from the team, and the reason for the block is communicated to them.
